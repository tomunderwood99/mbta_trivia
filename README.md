# MBTA Trivia
This is a repository of trivia questions about the MBTA, made by a fan. The questions can be accessed through the [GitHub Page](https://tomunderwood99.github.io/mbta_trivia/), or in the `questions.md` file.

## Modes
The play mode lets you answer questions at your own pace, while the event mode intiates a timed slideshow of randomized questions.

## Questions
Questions were picked from various sources, and may contain errors or become outdated. If you find an error, or wish to submit your own questions, please create an issue or submit a pull request.

## Run it locally

From the project folder:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
